# SOS団 拠点 (SOS団ファンサイト)

涼宮ハルヒの憂鬱シリーズを愛するファンのための、非公式ファンサイトプロジェクトです。

## 🌐 公開サイト
**[https://nashi39.github.io/sosproject-1/](https://nashi39.github.io/sosproject-1/)**

## 🚀 技術スタック
- **Core**: React 18, Vite
- **Logic**: JavaScript (ES6+)
- **Styling**: Vanilla CSS (CSS3)
- **Deployment**: GitHub Pages (`gh-pages`)

## ✨ 主な機能
- **STORY**: 作品のあらすじ紹介
- **CHARACTER**: 主要キャラクターの紹介
- **ON AIR**: 各話のエピソードガイドとあらすじ（メインストーリー、劇場版、スピンオフ）
- **MUSIC**: 楽曲紹介（円形カルーセルナビゲーション）
- **SNS**: 関連サイトへのリンク集
- **Responsive Design**: PCおよびモバイル環境に対応

## 🛠️ ローカル開発環境の構築

### インストール
```bash
npm install
```

### 開発用サーバーの起動
```bash
npm run dev
```

### デプロイ (GitHub Pages)
```bash
npm run deploy
```
